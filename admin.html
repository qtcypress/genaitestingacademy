Write a blog post

Paste a link to an article, a doc page or a blog you want to respond to. The assistant reads it and drafts a post in your voice — then you edit it until it sounds like you, and publish. Nothing goes live until you press Publish.

These go into the page's Article schema, not a meta keywords tag — Google has ignored that tag since 2009 and Bing treats it as a spam signal. What actually counts is the same words appearing in the title, the first paragraph and the headings, so put them there too.

Grant access manually

For bank transfer, cash, or comped students. Adds to any time they already have.

Give someone a project

Access to the course and access to a project are separate. A paid subscription opens the lessons; a project has to be granted here. If the address has not registered yet the grant waits for them, like a GitHub invite — they get it the moment they sign up.

Many at once

One email per line, or paste a column straight out of Excel. Nothing is written until you have seen the dry run.

Coupon codes

A code a student types on the projects page. Choose whether it opens access on the spot or raises a request for you to approve — a code that opens on the spot is the authorisation, so give it a redemption limit.

Waiting for your approval

Students who redeemed a code that needs checking. Approving gives them everything the code promises; rejecting hands the seat back to the code.
